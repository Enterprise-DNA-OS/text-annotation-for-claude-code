# Why a text review desk can run without a front end

The office work is source text, labels, reviewers, evidence and decisions. An operator asks for the next batch, reads the examples, records labels and resolves disagreements through the coding agent. Read-only HTML shows progress and produces the evidence pack.

A specialised editor gives fast highlighting, keyboard annotation, media playback, concurrent reviewer screens, offline collection and verified accounts. This base does not. It handles text classification and local review. Where people need a browser workbench or media annotation, Enterprise DNA scopes and builds that part of their version. It is not a full Datasaur clone.

The database remains portable. Claude Code, Codex, OpenCode and Cursor use the same instructions and CLI. No model calls or sending are built into the scripts. The operator remains responsible for where their coding agent processes source text.
