# /release

Run the recorded workflow below and report its result.

```bash
npm run annotation -- release --project=SUPPORT --code=SUPPORT-V1 --note="All items reviewed against current guidance" --actor="Release lead"
```

Release means a local frozen dataset, never publication. Every item in the project must be ready. Report any blocker and resolve it through the relevant command. Never bypass checks or drop awkward examples to improve the score.
